# Upstreams

`ex-ussr-kinship-research/` is a version-pinned Git submodule of Denis Shiryaev's original MIT repository. A source ZIP omits submodule content. If you cloned a git repository, run `git submodule update --init --recursive`. If using the source ZIP, clone the upstream separately only after confirming its current license and pin.

No source databases or personal genealogical documents from any upstream are mirrored in the core project.
